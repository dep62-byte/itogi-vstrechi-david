# Итоги встречи Давид · AI Booster

Скилл для Codex и Claude Code: превращает клиентскую встречу в редактируемую презентацию AI Booster в чёрно-бело-жёлтом стиле. Показывает процессы клиента, ручную работу, подходящие кейсы, команду, маршрут внедрения, три формата участия и следующие шаги.

Для браузерного Gemini создайте Gem с готовыми инструкциями и четырьмя файлами знаний. Терминал и Node.js не нужны. Пакет содержит профиль браузерной среды: он не обещает доступ к локальным файлам, независимым агентам или Google Drive, если таких инструментов нет в аккаунте. Подробности и ограничения — в инструкции выше.

## Давиду: как начать

Откройте Codex Desktop/CLI или Claude Code и вставьте:

> Установи скилл «Итоги встречи Давид» из https://github.com/dep62-byte/itogi-vstrechi-david. Скачай репозиторий, прочитай README.md и выполни установку в мой Codex. Сам проверь доступные средства создания и просмотра презентаций. Если нужен доступ к Google Drive, используй только мой разрешённый рабочий аккаунт и попроси подтвердить вход; не запрашивай пароль или токен. Не меняй мои существующие скиллы без проверки.

Для Claude Code замените «в мой Codex» на «в мой Claude Code». После установки откройте новый чат и отправьте запись/транскрипт или доступную рабочую ссылку вместе с командой:

> Примени «Итоги встречи Давид». Возьми имя клиента и дату из источника. Собери презентацию по фактам встречи, проверь условия и каждый слайд. Сохрани редактируемый PPTX. Перед загрузкой подтверди рабочий аккаунт и папку; если нет действующего разрешения на загрузку именно туда, спроси меня. Верни ссылку на проверенный результат.

Фраза «Итоги встречи Давит» тоже поддерживается. Обычный скилл «Итоги встречи» не заменяется.

## Установка вручную

Нужен Node.js 20 или новее. Из распакованной папки репозитория:

```sh
node scripts/install.mjs codex
# или
node scripts/install.mjs claude
```

Установщик копирует только скилл, инструкции и изображения. Он не устанавливает зависимости, не подключается к Google и не получает секреты. При обновлении своя предыдущая версия сохраняется вне каталога скиллов как резервная копия. Чужой скилл не перезаписывается.

## Что внутри

- Самодостаточные правила формата Давида, проверки фактов, часов, команды и коммерческих условий.
- Оформление 16:9, редактируемые текст/таблицы, финальная сетка из 30 возможностей.
- Три ранее опубликованных обезличенных изображения кейсов и семь карточек примеров.
- Снимок условий на 2 октября 2026 года, «Лёгкий старт: 16 недель» по правилу от 5 октября и правила работы с изменениями.
- Проверка пакета, установщик и тесты без сторонних зависимостей.

Это инструкции для агента, а не автономный генератор презентаций. Для сборки нужен доступный в среде инструмент презентаций; агент проверяет его до работы. Для Google Slides нужен разрешённый рабочий доступ. Публичная ссылка на GitHub сама по себе такого доступа не даёт. Если облако недоступно, результат сохраняется локально с честным статусом проверки.

## Важно для результата

Часы и даты берутся из встречи; отсутствующие значения не придумываются. Результат чужого кейса не становится обещанием клиенту. Скидки, внутренние расчёты и неподтверждённые условия не попадают в презентацию. При изменении программы агент сверяет её с разрешённым текущим источником; спорные поля оставляет «условия уточняются».

Известный вопрос выпуска: состав заказных разработок в Enterprise требует отдельного согласования. Пакет не обещает две разработки как безусловное включение в тариф. Расписание потока также подтверждается отдельно.

Транскрипты, аудио, клиентские презентации и доступы в этот репозиторий не входят. Агент не отправляет презентацию клиенту: это делает продавец.
